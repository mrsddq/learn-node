# Lesson Index

This repository is a Node and Express learning archive. Keep the course folders intact, and extract only complete apps into new repos.

## Review Path

1. `1Nodejs-TheBeginning/` - Node runtime, modules, and basic scripts.
2. `2Node.js-WritingOurFirstServer/` - HTTP server fundamentals.
3. `3MyFirstExpressAppAListOfContacts/` - Express, routes, templates, and rendering.
4. `4MyFirstExpressAppContinued/12DeletingAContact/` - most complete contact-list lesson.

## If Extracting A Project

- Start from `4MyFirstExpressAppContinued/12DeletingAContact/`.
- Rename folders to conventional lowercase paths.
- Add tests for routes and contact operations.
- Add screenshots and a deployment note.
- Keep this original repo archived.
